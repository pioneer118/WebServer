# RPC-YOLO
本项目设计了一套基于 C++ 分布式 RPC 框架的 YOLO 目标检测系统，支持多客户端上传检测图片，服务端完成实时目标检测并返回检测结果。项目以 Muduo 网络库的 Reactor 模型为基础搭建高并发 RPC 通信框架，通过自定义消息协议解决 TCP 粘包拆包问题，结合 Protobuf 实现请求响应数据的高效序列化与反序列化；集成 ZooKeeper 作为服务注册中心，实现服务的动态上下线感知，保障系统高可用性；基于pytorch训练并调优YOLO目标检测模型，并将训练好的YOLO 模型封装为可远程调用的 RPC 服务。本项目解决了传统目标检测模型在本地集成部署困难，容易受到硬件资源条件的限制，推理效率低的问题，实现了一种高可用、高性能、可扩展的目标检测推理服务。
