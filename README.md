# RPC-YOLO
本项目设计了一套基于 C++ 分布式 RPC 框架的 YOLO 目标检测系统，支持多客户端上传检测图片，服务端完成实时目标检测并返回检测结果。项目以 Muduo 网络库的 Reactor 模型为基础搭建高并发 RPC 通信框架，通过自定义消息协议解决 TCP 粘包拆包问题，结合 Protobuf 实现请求响应数据的高效序列化与反序列化；集成 ZooKeeper 作为服务注册中心，实现服务的动态上下线感知，保障系统高可用性；基于pytorch训练并调优YOLO目标检测模型，并将训练好的YOLO 模型封装为可远程调用的 RPC 服务。本项目解决了传统目标检测模型在本地集成部署困难，容易受到硬件资源条件的限制，推理效率低的问题，实现了一种高可用、高性能、可扩展的目标检测推理服务
作为项目核心负责人，我主要负责以下内容： 1、 高并发网络模型设计：基于 Muduo Reactor网络模型实现网络层，完成网络IO与RPC方法调用的解耦设计； 2、自定义通信协议：通过自定义消息格式、编解码器实现数据完整传输，解决TCP粘包/拆包问题；利用 Protobuf 完成请求/响应数据的高效序列化与反序列化，保证数据传输的性能和规范性； 3、服务注册与发现：集成 ZooKeeper 作为服务注册中心，完成检测服务的注册与发现功能，提供服务给客户端；引入Watcher机制监听Zookeeper节点变化，动态感知服务上下线，保证检测服务的可用性与实时性； 4、YOLO 模型部署与服务封装：使用 PyTorch 完成 YOLO 目标检测模型的训练与调优，通过 TensorRT 实现模型的 C++ 端推理加速部署，将检测推理功能封装为 RPC 服务接口，支持多客户端远程调用检测功能。
